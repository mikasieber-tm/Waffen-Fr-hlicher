# Waffen Frölicher — Mockup

Modernes Mockup-Redesign der Webseite [waffen-froelicher.ch](https://waffen-froelicher.ch/).

## Seiten

- `index.html` — Startseite mit Editorial-Hero
- `shop.html` — Online-Shop / Produkt-Showroom
- `schiessanlage.html` — Schiessanlage & Trainings
- `ueber-uns.html` — Über uns
- `kontakt.html` — Kontakt mit Formular

## Stack

Statisches HTML/CSS, keine Build-Tools nötig. Einfach `index.html` im Browser öffnen.
